## 検出・修正した不具合

追加141ケースの先行実行では3件が失敗した（同一原因）。Xのglob除外でfnmatchが「/」も含めて一致し、保護対象ディレクトリ内のファイルまで除外していた。d/D/eいずれの清掃でも再現。
パス全体のfnmatchをパス要素ごとの照合へ変更し、Xは指定ディレクトリを残しつつ、その内容を清掃するよう修正した。
xと子ディレクトリ境界にも同じ照合方法を適用した。

その後に200件を一括で再実行し、全件成功を確認した。
実際のsupervisor試験は隔離したstateディレクトリ、破壊的なファイル操作は一時ディレクトリ内で実行する。ダウンロードや実データの削除は行わない。
